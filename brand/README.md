# Quorum Bio brand assets
- `mark.svg` / `mark.png`: square logo (teal background), for avatars. `avatar-1024.png`: 1024 px version.
- `mark-rounded.svg`: logo with rounded corners, for headers (used in the Spaces as `logo.svg`).
- `wordmark.svg` / `wordmark.png`: logo + name + tagline, for light backgrounds; `wordmark-dark.*` for dark backgrounds.
Colours: teal #0F5F57, mint #7FE0C8, white. The Q's three dots are a small group of cells (quorum sensing).
PNGs are rendered from the SVGs with headless Edge.
